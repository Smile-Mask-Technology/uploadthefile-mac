# Contributing

Bug reports, fixes and small improvements are welcome. For a bigger change, open an issue first.

Before a pull request:

- `scripts/test.sh` passes (see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)).
- Words people read in the app or in `uptf` follow [docs/voice.md](docs/voice.md).
- Commit messages say what changed and why.

Security problems go to [SECURITY.md](SECURITY.md), not a public issue.
