# Contributing

Thanks for helping. Bug reports, fixes and small improvements are welcome; for a bigger change, open
an issue first so we can agree on the approach.

## Before you open a pull request

- `scripts/test.sh` passes (see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)).
- Words people read in the app or in `uptf` follow [docs/voice.md](docs/voice.md).
- No secrets, tokens, signing certificates or personal paths in code, tests or logs.

## This is a public repository

Everything here is public: code, comments, docs, commit messages, branch names, issues and pull
requests. Keep all of it about the code and the features:

- Write what changed and the technical reason (a bug, a platform limit, an API contract, a test).
- Leave out business and product reasoning, internal discussions and decisions, who asked for what,
  plans and dates that are not releases, review or audit write-ups, and names or paths of private
  repositories and internal tools.
- A comment explains the code it sits on. History of how a decision was reached does not belong in
  the repository.

Security problems: see [SECURITY.md](SECURITY.md), not a public issue.
